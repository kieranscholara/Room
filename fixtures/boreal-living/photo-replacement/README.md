# Fictional photographic replacement fixture

These are generated illustrations for the authorised Boreal Living test retailer, not real customer photographs or manufacturer assets.

- `source.png`: furnished fictional bedroom, also supplied as `../images/room.png`.
- `clean-room.png`: authored empty-background pixels used only by the labelled recorded cleanup adapter. The app applies them through the salesperson's reviewed removal mask; it does not replace the complete source photograph.
- `BL-LINEN-front.png`: supplied transparent catalogue view associated with the fictional BL-LINEN variant. Its authoritative catalogue dimensions are 1.8 × 2.1 × 1.15 metres; the image does not establish physical measurement accuracy or unseen viewpoints.
- `analysis.json`: recorded visible-object selections for the exact source hash, subject to human review/correction.
- `calibration.json`: reproducible **assumed fictional** 4 × 4.5 metre room and floor marks. These values are not a physically verified survey of a real room.

The local adapter recognises registered source hashes only. Arbitrary photos require configured live OpenAI processing and consent. The trial preserves the original source, uses actual selected catalogue pixels for furniture, and requires explicit cleanup/render application before confirmation and quotation.
